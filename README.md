Linear Equation Solver Using MATLAB
Task 2 — Solving Linear Equations

A simple MATLAB GUI tool for solving a system of two linear equations.
Technology Used: MATLAB , MATLAB GUI components , Matrix operations , MATLAB linear algebra
Features : Simple graphical user interface , Input fields for equation coefficients , Solve button , Clear button , Displays the values of x and y.
